1. Instalar o agente no novo servidor

Cadastre o servidor, baixe o instalador no cartão de credenciais, extraia o ZIP completo e execute como Administrador.

powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Agent.ps1

2. Criar conta MySQL somente leitura

Execute estes comandos no MySQL/MariaDB com uma conta administrativa local. Substitua a senha de exemplo por uma senha aleatória forte. A permissão serve apenas para listar bancos.

CREATE USER IF NOT EXISTS 'lm_monitor'@'localhost' IDENTIFIED BY 'SUBSTITUA_POR_SENHA_FORTE';
GRANT SHOW DATABASES ON *.* TO 'lm_monitor'@'localhost';
CREATE USER IF NOT EXISTS 'lm_monitor'@'127.0.0.1' IDENTIFIED BY 'SUBSTITUA_POR_SENHA_FORTE';
GRANT SHOW DATABASES ON *.* TO 'lm_monitor'@'127.0.0.1';

Depois, no PowerShell elevado, configure o arquivo CNF com a senha criada:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Configure-Existing-MySQL.ps1

3. Atualizar um agente já instalado

Use “Baixar atualização” no cartão do Windows Server. O arquivo agent.json e o token são preservados. Execute na pasta extraída:

powershell -NoProfile -ExecutionPolicy Bypass -File .\Update-Agent.ps1 -SkipMySQL

Conferir o serviço após a atualização:

Get-Service ServerManagerAgent

As ações remotas PM2 e XAMPP exigem agente atualizado, servidor online e uma conta administradora no painel. Reinicializações podem interromper aplicações e bancos ativos.
